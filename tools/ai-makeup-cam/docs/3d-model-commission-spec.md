# 3D 顔モデル 制作仕様書（発注用）

この文書は、本人の顔の 3D モデルの制作をお願いするための仕様書です。
完成したモデルは、本人用のリアルタイム・メイク補正ソフト（AI メイクカメラ）の
**学習データを作る**ためだけに使います（詳しくは「1. 用途」）。

## 1. 用途

- 発注者本人の顔を、**実写に近い 3D モデル**として作ってください。
- 録画した本人の表情（52 種類の表情値）と顔の向きをモデルに反映させ、
  Blender で 1 フレームずつ自動描画します。その画像を
  「メイク済みの本人」「歯並びを整えた本人」の**正解画像**として、小さな AI モデルの学習に使います。
- モデルそのものを、オンライン会議などで本人の代わりに映すことはありません。

---

## 2. 最重要方針

1. **顔の形は本人そのままにしてください。** 骨格・輪郭・目鼻の形や大きさ・肌の質感は理想化しないでください。
   理想化するのは **メイク** と **歯** だけです。
2. **実写に見えることを最優先にしてください。** CG らしい質感（つるつるの肌、真っ白な歯など）は避けてください。

---

## 3. 参考資料（発注者が用意するもの）

- 多方向からの顔写真：正面・左右 45°・左右 90°・上下。無表情・笑顔・口を開けた顔・歯を見せた顔
- 必要に応じて、スマートフォンなどによる 3D スキャンデータ
- メイクの参考写真（目標とするメイクをした本人の写真）
- 歯の参考資料：現在の歯の写真（正面・左右）と、理想とする歯並びのイメージ

追加の撮影条件（照明・解像度・枚数など）があれば、事前にご指定ください。

---

## 4. 技術要件

### 4.1 形状・トポロジー

- 頭部・顔・首の上部まで。髪は 4.6 を参照
- 表情変形に耐えるトポロジー（目・口まわりのエッジフロー）
- 可能であれば、研究用の汎用頭部モデル **FLAME** のトポロジーに合わせた版も納品してください（Wrap 系ツールでの転写で可）。
  対応できない場合はご相談ください（任意）
- 単位：cm。正面向き・無表情（ニュートラル）のポーズで納品

### 4.2 表情リグ（必須）

- **ARKit 準拠の 52 ブレンドシェイプ**を、**ARKit と同じ名前**で作成してください
  （例：`jawOpen`, `mouthSmileLeft`, `eyeBlinkRight` …）。
  ※ こちらで使う顔追跡（MediaPipe Face Landmarker）が、同じ名前の 52 値を出力するためです。
- ボーン：頭（首）・あご（`jawOpen` と連動）・左右の眼球（視線）
- 52 個すべてについて、0 → 1 の変形が自然で破綻しないこと

### 4.3 歯・口の中（最重要パーツ）

| パーツ | 動き |
|---|---|
| 上の歯・上の歯ぐき | 頭に固定 |
| 下の歯・下の歯ぐき | あごのボーンに追従 |
| 舌 | あごに追従（ブレンドシェイプ `tongueOut` に対応） |
| 口の中（口腔） | 暗く自然な陰影 |

- 歯は**それぞれ独立したオブジェクト**にしてください。
- 次の **2 バージョン**を作ってください。
  1. **現在の歯**：参考写真に合わせた、今の本人の歯並び・色
  2. **理想の歯**：歯並びを整え、色を自然に明るくしたもの（真っ白にはしない）
- どちらのバージョンも、唇との位置関係（口を閉じたときにはみ出さない）を確認してください。

### 4.4 テクスチャ・マテリアル

- 4K 以上の PBR テクスチャ：ベースカラー、ノーマル、ラフネス、スペキュラー、
  SSS（肌の透け感）またはトランスルーセンシー
- **ベースカラーは、すっぴんとメイクを分けてください。**
  メイクは**パーツごとに別のレイヤー（画像）**にしてください。
  - ファンデーション（肌補正）／チーク／アイシャドウ／アイライナー／眉／リップ
  - 各レイヤーはアルファ付き。合成時に濃さを変えられるようにしてください
- 歯・歯ぐき・舌・眼球も、実写に近い質感に（歯はわずかな透け感と自然な色ムラを残す）

### 4.5 目

- 眼球・角膜・涙の層（ツヤ）を分けてください。まつ毛は別オブジェクトに

### 4.6 髪

- **基本**：頭の形がわかる程度の簡易な髪（カード方式など）で構いません。
- **オプション（髪型の変更にも使う場合）**：次の髪型を、**それぞれ切り替えられる別の髪**として作ってください。
  見積もりは基本とオプションで分けてください。
  1. 現在の髪型（参考写真に合わせる）
  2. 理想の髪型（発注者が参考画像で指定。例：長さ・前髪あり／なし・分け目）
  3. 前髪のバリエーション（前髪あり／なし／流し前髪など、発注者が指定）
- オプションの髪の要件：
  - ストランド（グルーム）またはカード方式で、Cycles で実写に近く見えること
    （毛先の透け感、アホ毛の少なさは調整可能に）
  - 頭のボーンに追従し、うなずき・首振りの範囲で破綻しないこと（揺れの物理演算は不要）
  - 前髪は額・眉に自然に影を落とすこと
  - 髪色はマテリアルで変えられること

### 4.7 描画環境

- **Blender（最新の安定版）の Cycles** で、実写に近く描画できるシーンを一式用意してください。
  - カメラはウェブカメラ相当（画角 約 70〜80°、顔から 50〜70 cm）
  - 照明は HDRI で差し替えできるようにしてください
- こちらで **Python（bpy）から自動操作**します。オブジェクト名・シェイプキー名・ボーン名は
  英数字で、わかりやすく統一してください

## 5. 納品物

| # | 納品物 | 形式 |
|---|---|---|
| 1 | Blender ファイル一式（リグ・マテリアル・描画シーン込み） | `.blend`（テクスチャは同梱または相対パス） |
| 2 | 汎用形式の書き出し | `.fbx` または `.glb`（ブレンドシェイプ・ボーン込み） |
| 3 | テクスチャ一式 | `.png` / `.exr`（4.4 のレイヤー分け） |
| 4 | 歯の 2 バージョン | 同じファイル内で切り替え可能に（コレクション分けなど） |
| 5 | FLAME トポロジー版（任意） | `.obj` / `.fbx` |
| 6 | 確認用レンダリング | 正面・斜め・横 × 無表情・笑顔・口を開けた顔・`aa` `ii` `uu` `ee` `oo` の口の形。すっぴん／メイク、現在の歯／理想の歯（髪のオプションがある場合は、髪型ごと） |
| 7 | 簡単な説明書 | オブジェクト・シェイプキー・ボーン名の一覧と、レイヤーの切り替え方 |

### 検収の基準

- 6 の確認用レンダリングを並べたとき、**本人の写真と並べても違和感がない**こと
- 52 ブレンドシェイプとあご・視線を同時に動かしても、破綻（めり込み・突き抜け）がないこと
- 口を開けたとき、歯・歯ぐき・舌が自然に見えること
- 修正は（回数）回まで対応

## 7. 進め方（案）

1. 仕様のすり合わせ・見積もり
2. 形状の確認（ニュートラルの顔）← 本人に似ているかの確認が最重要
3. 表情リグの確認（52 ブレンドシェイプの一覧の動画など）
4. 歯（2 バージョン）・メイクのレイヤーの確認
5. 描画シーン・確認用レンダリング → 検収 → 納品 → データ削除の報告

**費用を抑えたい場合の分割案**：まず **4.3 の歯（2 バージョン）と口の中だけ**を先に発注することもできます
（顔全体はほかの方法で用意し、あとで追加発注）。

## 8. 発注者側の参考メモ（制作者に渡す必要はありません）

- 学習データの作り方：録画した表情 52 値・頭の向き・あごの開きを、Blender（bpy）でこのモデルに
  適用して描画 → すっぴんの映像とペアにして、差分だけを学ぶ小さい 2D モデルを学習
  → ONNX に書き出し → アプリ内で DirectML（RX 9070 XT）で実行
- Unreal Engine の MetaHuman で制作する場合は、**MetaHuman のライセンスで、Unreal Engine 以外での描画や
  AI 学習に使ってよいか**を必ず確認すること
- vast.ai などで学習する場合は、データセンター型（Secure Cloud）のマシンを選び、
  終わったらデータとインスタンスをすぐに削除すること
