# 案A：メイクの写真からプリセットを作る

対面の面接でするいつものメイクを写真に撮ると、同じ見た目になるプリセットをアプリが自動で作ります。
プログラムは `makeup_cam/analyze.py` です。写真はプリセットを作るときに読むだけで、どこにも保存しません
（顔の写真はリポジトリに入れないでください）。

## 1. 写真の撮り方

**メイクの写真と、すっぴんの写真の 2 枚を使ってください。** 1 枚だけでも作れますが、測れるのはリップや濃いチークなど一部だけです
（下の「精度の目安」）。同じ日に、すっぴんの写真を先に撮るのが理想です。詳しくは `docs/capture-guide.md` の 2 章です。

- 2 枚とも**同じ場所・同じ照明・同じカメラ**で撮ります。**構図と服も同じ**だと、色をいちばん正確に合わせられます
  （髪、服、首、背景の色の比で 2 枚をそろえます）
- **正面を向いて、無表情で**撮ります。2 枚で顔の向きや表情をそろえます（笑顔だと頬と目元が測れなくなります）
- 顔全体が大きく写り、髪や手で隠れていないこと。写っているのは本人だけにします
- **前髪は 2 枚とも上げて、眉を見せます。メガネは外します。** どちらかの写真で隠れていると、その項目は測れません
- 顔が白飛びしないように撮ります（白飛びすると、ファンデの色やチークを測れません）
- Web カメラでもスマホでも使えます。美肌モードやフィルタは切ってください。JPEG でも PNG でも構いません
- HEIC（iPhone の標準形式）は読み込めないので、JPEG に変換してください

## 2. 使い方

**設定画面**の「写真から作る…」から使えます（README の「写真から作る」）。解析は別スレッドで動くので、その間も画面は操作できます。ただし映像がカクついたり 1 秒ほど止まったりすることがあるので、面接中は実行しないでください。
どの項目も測れなかったときは保存しません。標準プリセットと同じ名前を指定すると、理由を表示して別の名前を聞き直します。

**コマンドライン**では次のどちらかです。

```bash
python -m makeup_cam --from-photo メイク.jpg --bare すっぴん.jpg --name いつものメイク
python -m makeup_cam.analyze メイク.jpg --bare すっぴん.jpg --name いつものメイク
```

`--from-photo` は設定画面と同じく、どの項目も測れなかったときは保存せず、終了コード 1 で終わります。測らない項目に使うプリセットは `--preset` で指定します。
`makeup_cam.analyze` のオプションは次のとおりです（どの項目も測れなくても保存します）。

| オプション | 意味 |
|---|---|
| `--bare すっぴん.jpg` | すっぴんの写真（省略できますが、あるとずっと正確です） |
| `--base natural` | 写真から測らない項目に使うプリセット（既定は `natural`） |
| `--name 名前` | 保存するプリセットの名前（必須。標準プリセットと同じ名前は使えません） |
| `--json 結果.json` | 測定した数値を書き出します（確認用） |

できたプリセットは、ふつうのプリセットと同じように選べます。項目ごとの信頼度（0〜1）とメモも表示されます。
**信頼度 0 の項目は測れなかったもの**で、値は `--base` のままです。メモに理由が出ます。
あとからスライダーで好きなように調整できます。全体のメイクの強さは 100% で保存します。

## 3. 何を測っているか

| 項目 | 測るもの | すっぴん写真なしのとき |
|---|---|---|
| リップ | 色、濃さ、質感（マット・サテン・グロス）、輪郭 | 肌の色から推定した「素の唇の色」と比べる。輪郭は測らない |
| チーク | 色、濃さ、形、大きさ、位置、ぼかし | 頬の赤みのふくらみから推定。**はっきりしたチークだけ** |
| アイシャドウ | 色、濃さ、高さ、ぼかし、ラメ | 眉の下の肌と比べて推定。**ほとんど測れない** |
| アイライナー | 色、濃さ、太さ、跳ね上げ、下のライン | 目尻の外の暗さだけで判断。**跳ね上げのないラインは見分けられない** |
| 眉 | 色、濃さ、太さ、ぼかし | 周りの肌との差から控えめに推定 |
| 肌 | ファンデの色と強さ、明るさ、なめらかさ、質感、カバー、赤み、クマ | ファンデの色だけ。ほかは `--base` のまま |
| シェーディング・ハイライト | 場所ごとの強さ | **測らない**（`--base` のまま） |
| 涙袋 | 強さ、幅、下の影 | **測らない**（`--base` のまま） |
| 歯・顔の形・髪・髪型 | 測らない（`--base` のまま） | 同じ |

**しくみ**：アプリのエフェクトをすっぴんの顔に実際にかけてみて、メイクの写真にいちばん近くなる設定を探します。
エフェクトの中身を調整しても、そのまま正しく動きます。

**色の合わせ方**：プリセットはすっぴんの顔にかけるものなので、すっぴん写真の明るさと色を基準にします。
メイクが乗らない部分（髪・服・首、なければ背景）の画素を 2 枚で比べ、露出と色かぶりの違いをメイクの写真から取り除きます。
階調の違い（カメラの露出やモードの違い）も、明暗の幅が十分あれば取り除きます。背景だけが変わった場合は、人物側を優先します。
どれも使えなければ首、それも無理ならおでこと口のまわりで合わせます（この場合、ファンデの色は測らず `--base` のままにします）。
背景がほぼ無彩色なら、色かぶりの補正もします。緑の壁のように色のついた背景では、壁の色と色かぶりを区別できないので補正しません。

**メイクらしくない変化は、メイクにしません**：次のような値は実際の化粧品にないので、その項目を `--base` のままにしてメモで知らせます。

- チーク：赤みが残らないほど暗い、または黒や灰色に近い変化（影や照明の違いと判断）
- アイシャドウ：黒に近い色が最大の濃さで出る変化。色の範囲はピンク・ブラウン・オリーブ系までで、青や緑は近い色に丸めます
- 眉：ブラウンとグレーの範囲に丸めます。前髪やフレームのように眉の上まで暗くなる変化は「隠れている」と判断します
- ファンデ：肌の色むらが整わないのに色だけ変わっている、または肌らしくない色になる変化（光の違いと判断）

## 4. 精度の目安

既知の設定を実際のパイプラインでかけた画像を「メイクの写真」にして、解析し、復元した設定で
もう一度かけ直して比べました（往復テスト）。女性 5 人（CREMA-D の 1029, 1060, 1074, 1072, 1013）× 16 種類のメイク、計 80 通り。
数値はかけ直した画像との色差（ΔE2000 の平均、最小〜最大）です。

| | すっぴん写真あり | すっぴん写真なし |
|---|---|---|
| 顔全体 | **0.0〜1.2**（平均 0.6） | 0.8〜2.2（平均 1.3） |
| 唇 | 0.0〜3.1（平均 0.9） | 0.0〜15.3（平均 3.2。ヌード系のリップを見落とすと大きくなる） |
| 頬 | 0.0〜1.8（平均 0.7） | 0.6〜3.8（平均 1.7） |
| まぶた | 0.0〜2.0（平均 0.7） | 0.7〜3.6（平均 2.1） |
| アイライン付近 | 0.0〜2.4（平均 0.7） | 0.4〜4.9（平均 2.4） |
| 眉 | 0.0〜3.3（平均 0.8） | 1.0〜11.1（平均 4.1） |

メイクの項目を見落とした数（あるのに濃さ 0.05 未満）と、ないのに出した数：

| | すっぴん写真あり | すっぴん写真なし |
|---|---|---|
| リップ | 見落とし 0/75、誤検出 0/5 | 見落とし 10/75（ベージュ系 5 件、ヌード系 3 件など）、誤検出 0/5 |
| チーク | 見落とし 0/65、誤検出 1/15 | 見落とし 44/65（濃いものだけ測れる）、誤検出 0/15 |
| アイシャドウ | 見落とし 7/65（うち 5 件は肌より明るいシャドウ）、誤検出 0/15 | **見落とし 65/65**、誤検出 0/15 |
| アイライナー | 見落とし 5/60、誤検出 5/20（見た目の差は色差 1 未満） | 見落とし 56/60、誤検出 1/20 |
| 眉 | 見落とし 0/70、誤検出 0/10 | 見落とし 28/70、誤検出 0/10 |

**すっぴん写真なしのアイシャドウ**：上のメイクはすべて濃さ 0.6 のブラウンで、1 枚では測れません。さらに濃いスモーキーメイク
（`#5A3A2E`、濃さ 0.9）でも、見つかったのは 5 人中 1 人（1072）だけでした。1 枚ではアイシャドウはほとんど測れないと考えてください。

- 色差は 1 でほとんど分からず、2〜3 でよく見れば分かる程度です
- 測った値が「元の設定の値」と同じになるとは限りません。チークやアイシャドウでは
  「薄い色を濃く」と「濃い色を薄く」が同じ見た目になるため、よくある化粧品らしい色の組み合わせを選んでいます。
  リップの濃さも同じ理由で 0.7 に寄せています。**見た目が同じになること**を目標にしています

**素顔だけで試した結果**（「メイクなし」と出てほしい場合）：

| | 2 枚（素顔どうし 99 組） | 1 枚（素顔 231 フレーム） |
|---|---|---|
| リップが出た数 | 2（1002 のみ。素で口紅に見える唇の人が口の形を変えたとき） | 21（すべて 1002）。ほかの 10 人は 0 |
| アイシャドウ（0.3 以上） | 0 | 0（0.05 以上は 1 件、最大 0.2） |
| チーク（0.05 以上） | 12（最大 0.22） | 1（0.06） |
| アイライナー（0.05 以上） | 1（0.74、見た目の差は色差 2 程度） | 0 |
| まぶたの色差（最大） | 2.83（`--base` の値を含む） | 1.02 |

2 枚のときの顔全体の色差は最大 2.38 です。これは、表情が違って測らなかった項目に残る `--base` の値（natural のシェーディングなど）を含みます。
階調や背景だけが違う素顔の 2 枚（ガンマ 0.8〜1.25、壁の色替え）では、ほぼ全項目 0 になり、顔全体の色差は多くが 0.05 未満です。
ガンマ 1.25 や暖色かぶりで肌が白飛びする組み合わせでは、ファンデとチークが `--base` の値になります（最大で色差 2 程度）。

## 5. 素の状態の基準

すっぴん写真がないときの「素の唇の色」「頬の赤み」「まぶたの暗さ」などの基準は、テスト素材の女性 11 人の
動画のフレームで測りました。そのうちアジア系は 1 人だけで、**日本人女性でも正しいかは未確認**です。
すっぴん写真を使うと、この基準はほとんど使いません。

## 6. 限界

- **本人の写真ではまだ試していません**。テストは合成したメイクだけで、本物の化粧品の写真は使っていません。
  マスカラ、ラメ、ベースメイクの質感など、エフェクトにないものは再現できません（近いもので代用します）
- 2 枚の写真で表情や顔の向きが違うと、すっぴん写真と比べるのは唇と眉だけになります。
  目の開き方だけが違うときは、まぶたとアイラインをメイクの写真から推定します
- **すっぴん写真なしでは、アイシャドウはほとんど測れません**。笑顔や話している顔の素のまぶたの暗さのほうが、
  アイシャドウの差より大きいためです（4 章の見落とし数を参照）。すっぴんの人にアイシャドウを出さないことを優先しました
- 明るいアイシャドウ（肌より明るくなるもの）は 2 枚あっても測りません（光の違いと区別できないため。濃さ 0 になります）
- アイライナーは、シャドウの残りを細いラインとして拾うことがあります（ラインなしのメイク 20 例中 5 例。見た目の差は色差 1 未満です）
- 素の唇が口紅のように濃い人は、すっぴん写真なしだと口紅があると判定されます（1002）。2 枚でも口の形が違うと出ることがあります
- 肌がとても明るい・白飛びぎみの顔では、ハイライトの強さとファンデの色を正しく測れません
- **別人の写真を 2 枚入れても検出できません**（顔の形だけでは同じ人かどうかを判定できませんでした）。
  取り違えると、唇と眉の値は意味のないものになります
- メガネと前髪の検出は、合成した画像でしか試していません。薄いフレームや、肌の色に近いもの（手など）は見落とすことがあります

## 7. エラーと「測れない」とき

次の場合はエラーになり、プリセットは保存しません（日本語のメッセージを表示します）：
顔が見つからない、複数の顔が写っている、顔が小さすぎる（目の間隔が 28 ピクセル未満）、顔が横を向きすぎている、読み込めないファイル、
標準プリセットと同じ名前、`--json` の書き出し先に書けない。

次の場合はエラーにせず、その項目だけ `--base` の値を使い（信頼度 0）、メモで知らせます：
前髪、手、メガネ、マスクで隠れている項目。白飛びしている頬や唇。メイクらしくない変化（3 章）。
白黒の写真、ネガ、強い色フィルタの写真は肌の色を読めないので、**すべての項目**を `--base` の値にします。
