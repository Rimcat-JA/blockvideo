# AI メイクカメラ

Web カメラの映像に、**自然なメイクをリアルタイムでかけて**、Zoom・Microsoft Teams・Google Meet などに
「カメラ」として映すためのアプリです。オンラインの就職面接で使うことを想定し、
**相手にフィルターだと気づかれない自然さ**と、**すべての値を自分で細かく調整できること**を重視しています。

- 肌（なめらかさ・シミ・赤み・クマ・ファンデの色・明るさ）、リップ、チーク、アイシャドウ、アイライナー、眉、
  髪（ツヤ・まとまり・髪色・明るさ・コントラスト）を、スライダーで 1 項目ずつ調整できます
- 設定画面で、メイク前（すっぴん）とメイク後をボタン 1 つで見比べられます
- GPU 不要（CPU だけで動きます）。Windows と macOS に対応（Linux でも動きます）
- 処理中にエラーが起きても止まりません。顔が映っていないときは、メイクがふわっと消えて元の映像になります

> 顔の形（輪郭・目の大きさなど）は変えません。変えるのは「メイク」と「髪の質感」だけです。

## 1. しくみ

```
Web カメラ
   │ 映像
   ▼
AI メイクカメラ（このアプリ）
   1. 顔の位置を検出（478 点）
   2. 髪・肌の領域を検出
   3. 髪 → 肌 → 眉 → アイシャドウ → アイライナー → チーク → リップ の順にメイクを重ねる
   4. 設定画面にプレビューを表示
   │ メイク済みの映像
   ▼
OBS Virtual Camera（仮想カメラ）
   │
   ▼
Zoom / Teams / Google Meet のカメラで「OBS Virtual Camera」を選ぶ
```

- 顔の検出と髪・肌の検出には、Google の MediaPipe（顔のランドマーク検出・セグメンテーション）を使います。
- メイク済みの映像は「仮想カメラ」に送られます。仮想カメラのドライバーは **OBS Studio に付属**しているので、
  OBS Studio をインストールしておく必要があります（OBS を配信に使う必要はありません）。
- すべて自分の PC の中で処理します。映像がインターネットに送られることはありません
  （インターネットを使うのは、初回に顔認識モデルをダウンロードするときだけです）。

## 2. 必要なもの

| 項目 | 内容 |
|---|---|
| OS | Windows 10 / 11、macOS（OBS Studio 30 以降と Python 3.12 が動くバージョン）。Linux でも動作します |
| Python | **3.12 を推奨**（3.10〜3.12）。MediaPipe が対応しているバージョンを使ってください |
| OBS Studio | Windows は 26 以降、macOS は 30 以降（仮想カメラのため） |
| Web カメラ | 内蔵カメラ・USB カメラのどちらでも可。1280×720 / 30fps 推奨 |
| PC の性能 | 一般的なノート PC の CPU で 1280×720・24fps 以上が目安。重い場合は解像度を下げられます |
| ディスク | Python ライブラリ 約 1 GB ＋ 顔認識モデル 約 20 MB |

## 3. OBS Studio のインストール（仮想カメラのため）

このアプリは、OBS Studio に付属する仮想カメラ「OBS Virtual Camera」を通して映像を Zoom などに渡します。

### Windows

1. <https://obsproject.com/> から OBS Studio（**バージョン 26 以降**）をダウンロードしてインストールします。
2. インストールが終わったら、**Zoom・Teams・ブラウザを再起動**します（新しいカメラを認識させるため）。
3. OBS Studio 自体は起動しなくてかまいません。**OBS で「仮想カメラ開始」を押している場合は停止してください**
   （OBS とこのアプリは同時に仮想カメラを使えません）。

### macOS

1. <https://obsproject.com/> から OBS Studio（**バージョン 30 以降**）をダウンロードし、
   「アプリケーション」フォルダに入れます。
2. **OBS を一度起動し、右下の「仮想カメラ開始」を 1 回クリック**します。仮想カメラのシステム拡張がインストールされます。
3. 「システム機能拡張がブロックされました」と表示されたら、
   「システム設定 → 一般 → ログイン項目と機能拡張」（macOS 13/14 は「プライバシーとセキュリティ」）で許可します。
4. 許可できたら OBS の「仮想カメラ停止」を押して **OBS を終了**し、Zoom などを再起動します。

### Linux（参考）

```bash
sudo apt install v4l2loopback-dkms
sudo modprobe v4l2loopback devices=1 exclusive_caps=1 card_label="AI Makeup Cam"
```

## 4. セットアップ

### いちばん簡単な方法（起動用ファイルをダブルクリック）

このフォルダ（`tools/ai-makeup-cam`）にある起動用ファイルを使うと、初回に自動で
Python の仮想環境（`.venv`）を作り、必要なライブラリをインストールしてから起動します。
2 回目以降はすぐに起動します（`requirements.txt` が変わったときだけ再インストールします）。

| OS | ファイル | 使い方 |
|---|---|---|
| Windows | `start_windows.bat` | ダブルクリック。`py -3.12`（なければ `python`）を使います |
| macOS | `start_mac.command` | ダブルクリック（下の注意を参照）。`python3.12`（なければ `python3`）を使います |
| Linux | `start_linux.sh` | ターミナルで `./start_linux.sh` |

先に Python 3.12 をインストールしておいてください。

- Windows: <https://www.python.org/downloads/windows/> からインストールし、
  **「Add python.exe to PATH」にチェック**を入れます。
- macOS: <https://www.python.org/downloads/macos/> からインストールします（Homebrew の `brew install python@3.12` でも可）。
  python.org 版を入れたあと、「アプリケーション → Python 3.12」フォルダの **`Install Certificates.command` を一度実行**してください
  （モデルのダウンロードで SSL エラーになるのを防ぎます）。

> **macOS の注意**：初めて `start_mac.command` をダブルクリックすると「開発元を確認できないため開けません」と表示されることがあります。
> その場合は Finder でファイルを **右クリック →「開く」** を選ぶと実行できます。
> 実行できない（権限がない）と表示された場合は、ターミナルで `chmod +x start_mac.command` を実行してください。

起動用ファイルにはオプションも渡せます（例：`start_windows.bat --preset polished`）。

### 手動でセットアップする方法

**Windows（PowerShell）**

```powershell
cd path\to\tools\ai-makeup-cam
py -3.12 -m venv .venv
.venv\Scripts\Activate.ps1          # 実行できない場合: Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python -m makeup_cam
```

**macOS（ターミナル）**

```bash
cd path/to/tools/ai-makeup-cam
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python -m makeup_cam
```

## 5. 初めての起動

1. 起動すると、**顔認識モデル（合計 約 20 MB）を Google の MediaPipe 公式ストレージからダウンロード**します（初回のみ）。
   ダウンロードしたファイルは SHA-256 で検証してから、次の場所に保存されます。

   | OS | 保存先 |
   |---|---|
   | Windows | `%LOCALAPPDATA%\ai-makeup-cam\models` |
   | macOS | `~/Library/Application Support/ai-makeup-cam/models` |
   | Linux | `~/.local/share/ai-makeup-cam/models` |

   オフラインの PC では、エラーメッセージに表示される URL から 2 つのファイルを手動でダウンロードして上のフォルダに置いてください。
   `python -m makeup_cam --download-models` で、ダウンロードだけを先に済ませることもできます。
2. **macOS では、カメラの使用許可を求めるダイアログ**が出ます。「許可」を選んでください
   （許可するのは、このアプリを起動したターミナルなどのアプリです）。
3. 設定画面が開き、左にプレビュー、右に設定が表示されます。初回は標準プリセット「natural（就活ナチュラル）」で始まります。
4. 画面下のステータスバーに `顔検出 OK`、`FPS`、`処理 ms`、`仮想カメラ OBS Virtual Camera` が表示されれば準備完了です。

> 起動時にターミナルへ `W0000 ...` や `INFO: Created TensorFlow Lite XNNPACK delegate` などの英語のログが出ますが、
> MediaPipe が出す情報なので気にしなくて大丈夫です。

## 6. Zoom・Teams・Google Meet でカメラを選ぶ

**先にこのアプリを起動してから**、各アプリのカメラで **「OBS Virtual Camera」** を選びます。

| アプリ | 操作 |
|---|---|
| Zoom | 「設定 → ビデオ → カメラ」で「OBS Virtual Camera」を選ぶ。ミーティング中はビデオボタン横の「^」からも選べます |
| Microsoft Teams | 「設定 → デバイス → カメラ」、または会議に参加する前の画面のカメラ設定で選ぶ |
| Google Meet | 会議に入る前の画面、または「その他のオプション（⋮）→ 設定 → 動画 → カメラ」で選ぶ |
| ブラウザで受ける面接サイト | このアプリを起動してから**ページを再読み込み**し、カメラの選択欄で選ぶ。ブラウザにカメラの許可を求められたら許可する |

- **元の Web カメラは選ばないでください**（このアプリが使用中のため、ほかのアプリからは開けないことがあります）。
- 自分の映像が左右反転して見えるのは Zoom などの表示上の仕様で、相手には正しい向きで映っています
  （「全体」タブの「相手への映像も左右反転」は通常 OFF のままにしてください）。
- このアプリの画面を閉じると仮想カメラも止まります。面接中は閉じないでください（最小化は問題ありません）。
- 本番の前に、Zoom の「ビデオのプレビュー」や Meet の待機画面で、映り方を必ず確認してください。

## 7. 設定画面の使い方

| 場所 | できること |
|---|---|
| 上部「カメラ」 | 使う Web カメラを選びます。「↻」でカメラを探し直します。OBS Virtual Camera などの仮想カメラは一覧に出ません |
| 上部「解像度」 | カメラから取り込む解像度です（1280×720 / 960×540 / 640×480）。動作が重いときは下げてください。相手に送る映像の形は 16:9（1280×720）のままです。変えるとカメラをつなぎ直すので、相手の映像が少し止まります。長引くと「Camera reconnecting...」の画面に替わります。640×480 は 4:3 なので、左右に黒帯が入ります |
| 上部「仮想カメラ出力」 | オフにすると仮想カメラへの出力を止めます（設定の確認だけしたいとき） |
| 上部「メイクOFF」 | メイクをすべて外した映像を相手に送ります |
| 上部「比較（すっぴん）」 | **押している間だけ**、プレビューにメイク前の映像を表示します（相手の映像は変わりません）。**スペースキー**でも同じです |
| 右上「プリセット」 | プリセットの選択・保存・名前を付けて保存・削除・初期値に戻す。設定を変えると「● 変更あり」と表示されます |
| 右のタブ | 全体・肌・リップ・チーク・アイシャドウ・アイライナー・眉・髪。値はすぐにプレビューと相手の映像に反映されます |
| 各項目の「↺」 | その項目だけ初期値に戻します。項目にマウスを乗せると説明が表示されます |
| 下部ステータスバー | 顔検出 OK/NG、FPS、1 フレームの処理時間、仮想カメラの状態、エラーの詳細 |

- 設定は変更の 1 秒後に自動保存され、次回の起動時に復元されます。
- マウスホイールで値を変えるときは、先にその項目をクリックします（画面をスクロールしただけで値が変わらないようにしています）。

## 8. 設定項目の一覧

数値はスライダーの範囲です。「初期値」は各項目の ↺ で戻る値、「natural」は標準プリセットの値です。
濃さ・強さを 0 にすると、その効果は完全にかからなくなります。

### 全体

| 項目 | 範囲 | 初期値 | 説明 |
|---|---|---|---|
| 全体のメイクの強さ | 0〜1 | 1.0 | すべてのメイクの濃さをまとめて調整します。「少し薄く」したいときはまずここを下げます |
| プレビューを鏡像にする | ON/OFF | ON | 自分のプレビューだけを左右反転します（相手には影響しません） |
| 相手への映像も左右反転 | ON/OFF | OFF | 通常は OFF。相手に送る映像を反転します |
| 顔追跡のなめらかさ | 0〜1 | 0.5 | 上げるとメイクの揺れが減り、下げると速い動きによく追従します |
| 髪・肌の検出間隔（フレーム） | 1〜6 | 2 | 髪と肌の検出を何フレームごとに行うか。大きいほど軽くなりますが、髪の追従が遅れます |
| 顔の検出点を表示（確認用） | ON/OFF | OFF | プレビューに顔の検出点を表示します（相手には映りません） |

### 肌

| 項目 | 範囲 | 初期値 | natural | 説明 |
|---|---|---|---|---|
| 肌補正を使う | ON/OFF | ON | ON | |

| 質感を残す | 0〜1 | 0.35 | 0.40 | 毛穴などの細かい質感を残し、塗りすぎ感を防ぎます |
| シミ・ニキビ跡カバー | 0〜1 | 0.5 | 0.5 | 小さな点状の色ムラを周りの肌になじませます（ほうれい線などの線は消しません） |

| クマ補正（コンシーラー） | 0〜1 | 0.3 | 0.3 | 目の下の暗さ・青みを明るくします |

## 9. プリセット

標準で 4 つのプリセットが入っています。ファイル名は環境によって文字化けしないように英語にしています。

| プリセット名（画面の表示） | 内容 |
|---|---|
| `natural`（就活ナチュラル） | **起動時の標準**。面接向けの薄いメイク。肌を整え、血色のよいリップ・チーク、目元をほんのり引き締めます |
| `bare`（すっぴん風補正） | ほぼ色を足さない補正。肌のムラ・クマ・赤みと髪のツヤだけを整え、リップはごく薄く、チーク・アイメイクはオフ |
| `polished`（しっかりメイク） | 一目でメイクしていると分かる、オフィス向けのしっかりメイク。濃いめのローズリップ、アイライン、アイシャドウ |
| `off`（全部オフ） | すべての補正をオフにした状態 |

- 好みに調整したら「名前を付けて保存…」で自分のプリセットとして保存できます（日本語の名前も使えます）。
  保存先は Windows `%LOCALAPPDATA%\ai-makeup-cam\presets`、macOS `~/Library/Application Support/ai-makeup-cam/presets` です。
- 標準プリセットと同じ名前で保存すると、自分のプリセットが優先されます。削除すると標準のものに戻ります。
- プリセットは JSON ファイルなので、テキストエディタでも編集できます。範囲外の値は自動で範囲内に収められ、
  足りない項目は初期値になります。
- 起動時は「前回の設定」→（なければ）`natural` → 初期値の順に読み込みます。

## 10. 面接で使うときのコツ

- **照明が一番大切です。** 顔の正面（カメラの少し上）から明るく照らし、窓を背にしないようにします。
  明るい映像ほど検出が安定し、メイクも自然に見えます。
- **本番前に必ずテスト録画をします。** Zoom の録画や Meet の待機画面で、話す・笑う・うなずく・横を向くといった動きを確認し、
  不自然なところがあれば「全体のメイクの強さ」を下げてください。
- **「少し物足りない」くらいがちょうどよいです。** プレビューは自分の顔を大きく見るので濃さが気になりにくく、
  相手の画面では小さく映ります。迷ったら `natural` を基準にしてください。
- **顔の形は変えないでください（このアプリにもその機能はありません）。** 面接は本人確認の場でもあります。
  メイクや身だしなみの範囲にとどめ、別人のように見える加工はしないことをおすすめします。
- 面接の直前には「比較（すっぴん）」を押して、メイク前後の差が大きすぎないか確認しましょう。
- 動作が重い PC では、面接中にほかのアプリ（ブラウザのタブなど）を閉じておくと安定します。

## 11. 困ったとき

| 症状 | 対処 |
|---|---|
| 「カメラ ○ を開けませんでした」と表示される | ほかのアプリ（Zoom・Teams・ブラウザ・OBS など）が Web カメラを使っていないか確認し、閉じてから「↻」を押します。Windows は「設定 → プライバシーとセキュリティ → カメラ」で「デスクトップ アプリがカメラにアクセスできるようにする」をオンにします |
| macOS でカメラが映らない | 「システム設定 → プライバシーとセキュリティ → カメラ」で、このアプリを起動したアプリ（ターミナル・iTerm・VS Code など）をオンにし、そのアプリを再起動します |
| 「仮想カメラを開始できませんでした」と表示される | OBS Studio をインストールしているか確認します（[3 章](#3-obs-studio-のインストール仮想カメラのため)）。OBS で「仮想カメラ開始」を押している場合は停止します。「いまは使用中です」と出るときは、Zoom などのカメラを一度オフにしてからオンに戻します。macOS ではシステム拡張を許可したか確認します |
| Zoom などに「OBS Virtual Camera」が出てこない | OBS をインストールしたあとに Zoom・Teams・ブラウザを**再起動**します。ブラウザの面接サイトはページを再読み込みします |
| 相手の画面が真っ黒・止まっている | このアプリが起動しているか、「仮想カメラ出力」がオンか確認します。カメラが外れると「Camera reconnecting...」という画面が送られ、2 秒ごとに再接続を試みます |
| 相手の画面に OBS のロゴが映る | このアプリが映像を送っていません。アプリが起動しているか、「仮想カメラ出力」がオンか確認します |
| 顔が細長く（または横に広がって）映る | OBS Virtual Camera は、会議アプリが要求した形に映像を引き伸ばします。このアプリは 16:9 で送るので、会議アプリ側が 4:3（640×480 など）を要求すると顔が細く映ります。会議アプリのカメラ設定で 16:9 や HD を選び、ビデオのプレビューで確認してください |
| 映像がカクカクする・FPS が低い | 「解像度」を 960×540 か 640×480 に下げる、「全体」タブの「髪・肌の検出間隔」を 3〜4 に上げる、「髪の補正を使う」をオフにする、ほかの重いアプリを閉じる、の順に試します |
| メイクが揺れる・ずれる | 「顔追跡のなめらかさ」を上げます。部屋を明るくすると検出が安定します |
| 「○○は仮想カメラなので、カメラの入力には使えません」と表示される | OBS Virtual Camera などの仮想カメラを入力にすると映像がループするので、開かないようにしています（Windows・Linux）。Web カメラを接続して「↻」を押してください。映像は止まらず「Camera reconnecting...」の画面が送られ続けます |
| 「○○が見つかりません」と表示される | 選んでいたカメラが外れています。つなぎ直すと自動で再開します。別のカメラを使うときは「↻」を押します |
| 「カメラの一覧を取得できないため…」と表示される | Windows がカメラの一覧を返せない間は、仮想カメラを開いて映像がループしないよう、カメラを開かずに待ちます。一覧が戻ると自動で再開します。直らないときは PC を再起動してください |
| 自分の映像が無限に重なって見える（合わせ鏡のよう） | このアプリの「カメラ」で仮想カメラを選んでしまっています（名前で判別できない仮想カメラや macOS の場合）。実際の Web カメラを選び直してください |
| 「顔が見つかりません」と表示される | 顔がカメラの正面に大きめに映るようにし、明るくします。顔が見つからない間は、メイクなし（髪の補正だけ）の映像が送られます |
| モデルのダウンロードに失敗する | インターネット接続を確認します。macOS で SSL のエラーが出る場合は、Python のフォルダにある `Install Certificates.command` を実行します |
| 「mediapipe が見つからない」というインストールエラー | Python のバージョンが新しすぎる可能性があります。Python 3.12 を入れ、`.venv` フォルダを削除してから起動し直してください |
| 起動後すぐ終了してしまう | ターミナルのメッセージを確認します。`python -m makeup_cam --verbose` で詳しいログを表示できます |

## 12. コマンドラインでの使い方

`python -m makeup_cam --help` で一覧を表示できます。

| コマンド | 内容 |
|---|---|
| `python -m makeup_cam` | 設定画面を開きます（通常の使い方） |
| `python -m makeup_cam --preset polished` | プリセットを指定して設定画面を開きます |
| `python -m makeup_cam --headless --preset natural` | 画面を出さずに、カメラ → メイク → 仮想カメラを実行します。状態を数秒ごとに表示し、Ctrl+C で終了します |
| `python -m makeup_cam --headless --settings my.json` | 自分で書いた設定ファイル（プリセットと同じ JSON）を使います |
| `python -m makeup_cam --image in.jpg --out out.png --compare` | カメラなしで、写真にメイクをかけて保存します。`--compare` で左右に「BEFORE / AFTER」を並べます |
| `python -m makeup_cam --list-cameras` | カメラの番号と名前を表示します |
| `python -m makeup_cam --download-models` | 顔認識モデルのダウンロードだけを行います |
| `python -m makeup_cam --camera-file 動画.mp4` | カメラの代わりに動画ファイルを使います（下の「カメラなしでテストする」） |

共通オプション：`--camera N`（カメラ番号）、`--width W --height H`（解像度）、`--fps F`、`--no-virtual-camera`（仮想カメラに出力しない）、`--verbose`（詳しいログ）。
`--preset` / `--settings` を省略した `--headless` と `--image` は、設定画面と同じく「前回の設定」（なければ `natural`）を使います。

環境変数：`AI_MAKEUP_CAM_HOME`（設定・プリセット・モデルの保存先を変更）、`AI_MAKEUP_CAM_MODELS_DIR`（モデルの場所だけを変更）。

### カメラなしでテストする（`--camera-file`）

Web カメラがなくても、動画ファイルをカメラの代わりにしてアプリ全体を動かせます。**動作確認用の機能で、面接本番では使いません。**

```bash
python -m makeup_cam --camera-file 動画.mp4                                 # 設定画面で確認
python -m makeup_cam --headless --camera-file 動画.mp4 --no-virtual-camera  # 画面なしで FPS と処理時間を確認
```

- 動画はファイルのフレームレートで実時間どおりに再生され、最後まで行くと最初に戻ります。指定の解像度に合わせて拡大し、余る部分は黒帯になります。2 fps 未満の動画は同じコマを繰り返して実時間を保ちます。フレームレートが不明か 240 fps を超える動画は、`--fps` の速さで再生します。
- 映像のないファイル（音声だけの .mp3 や .wav など）は、エラーを表示して終了します。
- 設定画面の「カメラ」には「動画ファイル: ファイル名」だけが表示されます。保存済みのカメラの選択は変わりません。
- `--camera` と同時には指定できません。

## 13. 開発者向け：構成と新しいエフェクトの追加

### 構成

```
makeup_cam/
  __main__.py      コマンドライン（GUI / --headless / --image など）
  gui.py           PySide6 の設定画面（設定項目のタブは config.py から自動生成）
  runner.py        カメラ → パイプライン → 仮想カメラ を動かす 2 本のスレッド（取り込み・出力）
  camera.py        Web カメラ入力（OS ごとのバックエンド）と仮想カメラ出力（pyvirtualcam）
  pipeline.py      1 フレームの処理：顔追跡 → 髪・肌の検出 → エフェクトを順に適用、フェード、エラーの隔離
  tracking.py      MediaPipe Face Landmarker（478 点）＋ One Euro フィルターによる揺れ止め
  segmentation.py  MediaPipe selfie multiclass による髪・顔の肌・体の肌のマスク（別スレッドで間引き実行）
  regions.py       ランドマーク番号と、唇・まぶた・眉などの領域マスク
  blend.py         ブレンド（乗算・ソフトライト・Lab の色置き換えなど）
  models.py        モデルのダウンロードと SHA-256 検証
  config.py        すべての設定項目（範囲・ラベル・説明）。GUI とプリセットの元になります
  presets.py       プリセットと前回の設定の保存・読み込み
  presets/*.json   標準プリセット
  effects/         エフェクト（hair, skin, brows, eyes, blush, lips）
```

- エフェクトは、フレームを float32 の BGR（0〜1）で受け取り、顔の周りの小さな領域（ROI）だけを処理します。
- 大きさはすべて顔の大きさ（目と目の距離）を基準にしているので、カメラとの距離が変わっても見た目が変わりません。
- 1 つのエフェクトで例外が起きても、ログに 1 回だけ記録してそのエフェクトだけを飛ばし、映像は止まりません。

### 新しいエフェクトを追加する（例：将来のヘアスタイル変更）

1. `config.py` に設定のセクションを追加し、`SECTIONS` と `SECTION_LABELS` に登録します。
   ```python
   @dataclass
   class HairstyleSettings:
       enabled: bool = flag(False, "ヘアスタイルを使う")
       volume: float = num(0.0, -0.5, 0.5, "ボリューム", help="…")
   ```
2. `makeup_cam/effects/hairstyle.py` を作り、`Effect` を継承したクラスを `@register_effect` で登録します。
   `name` はセクション名と同じにします。
   ```python
   @register_effect
   class HairstyleEffect(Effect):
       name = "hairstyle"
       order = 15              # 小さいほど先に実行（髪=10、肌=20）
       needs_face = True
       needs_hair_mask = True  # 髪のマスクが必要なら True（パイプラインが検出を実行します）

       def apply(self, frame, ctx, settings):
           ...                 # ctx.landmarks, ctx.hair_mask などを使い、強さは ctx.intensity を掛ける
           return frame
   ```
3. `effects/__init__.py` の `BUILTIN_EFFECT_MODULES` にモジュール名を追加します。

これだけで、設定画面のタブ・プリセットへの保存・コマンドラインのすべてに自動で反映されます。
エフェクトのルール：スライダーが 0 のときは**完全に何もしない**こと、強さに `ctx.intensity` を掛けること、
サイズは `regions.face_scale()` を基準にすること、ROI の中だけを処理すること。

## 14. テストの実行

```bash
python -m pip install -r requirements-dev.txt
python -m pytest -q
```

- テスト用の顔写真は scikit-image に含まれるパブリックドメインの画像（NASA の宇宙飛行士の肖像）を使います。
- 実際のモデルを使うテストは、環境変数 `AI_MAKEUP_CAM_MODELS_DIR` にモデルのあるフォルダを指定したときだけ実行されます
  （指定しない場合はスキップされます）。例：`AI_MAKEUP_CAM_MODELS_DIR="$HOME/Library/Application Support/ai-makeup-cam/models" python -m pytest -q`
- GUI のテストは画面なしでも動きます（Linux の CI では `QT_QPA_PLATFORM=offscreen` を指定してください）。
