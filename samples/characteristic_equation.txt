皆さん、こんにちは。
今日は、線形代数の「特性方程式」を学びます。
特性方程式は、行列の「固有値」を求めるための式です。
見終えるころには、二行二列の行列の固有値を、自分で求められるようになります。

```slide 今日のテーマ
  特性方程式

      │
      ▼

  固有値 を求める式
```

では、今日の流れを見てください。
まず、行列を掛けても「向きが変わらないベクトル」を見ます。
次に、そのベクトルを探すために、「特性方程式を導く」ことをします。
そして、具体的な行列で、実際に解いてみます。

```slide 今日の流れ
    1. 向きが変わらないベクトル
    2. 特性方程式を導く
    3. 例で解く
    4. まとめ
```

では、一つ目の「向きが変わらないベクトル」から始めます。
行列をベクトルに掛けると、ふつうはベクトルの向きが変わります。
ところが、掛けても向きが変わらない、特別なベクトルがあります。
それは、どんなベクトルでしょうか。

```slide 今日の流れ
  ▶ 1. 向きが変わらないベクトル
    2. 特性方程式を導く
    3. 例で解く
    4. まとめ
```

画面の行列Aを見てください。
この動画では、最後まで、このAを例に使います。
まず、横向きのベクトル、つまり成分が1と0のベクトルにAを掛けます。
結果は、成分が2と1のベクトルで、斜め上を向きました。
つまり、Aを掛けると「向きが変わる」のです。

```slide 例の行列 A
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
   A = ┌ 2  1 ┐
       └ 1  2 ┘

   A (1, 0) = (2, 1)    向きが変わる

   A (1, 1) = ？
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

次に、成分が両方とも1のベクトルに、Aを掛けてみます。
計算すると、成分が両方とも3のベクトルになります。
向きは同じで、長さだけが3倍になりました。
ポイントは、このベクトルはAを掛けても「向きが変わらない」ことです。

```slide 例の行列 A
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
   A = ┌ 2  1 ┐
       └ 1  2 ┘

   A (1, 0) = (2, 1)    向きが変わる

   A (1, 1) = (3, 3)    向きが変わらない
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

この特別なベクトルに、名前を付けます。
Aを掛けても向きが変わらないベクトルを、「固有ベクトル」と呼びます。
そのとき長さが何倍になるかを、「固有値」と呼びます。
今の例では、固有ベクトルは成分が両方とも1のベクトルで、固有値は3です。

```slide 名前を付ける
  固有ベクトル   向きが変わらないベクトル
                 例: (1, 1)

  固有値         長さの倍率
                 例: 3
```

では、今の話を式で書きます。
固有ベクトルを英字のx、固有値をギリシャ文字のλで表します。
画面の式は、左と右が同じになる、と言っています。
左はxにAを掛けたもの、右はxをλ倍したものです。
ただし、xはゼロベクトルではないとします。

```slide 式で書く
    A x = λ x

    x  : 固有ベクトル（ゼロでない）
    λ  : 固有値
```

なぜ、ゼロベクトルを除くのでしょうか。
ゼロベクトルは、どんな行列を掛けても、ゼロのままです。
すると、λがいくつでも、式が成り立ってしまいます。
だから、ゼロベクトルは固有ベクトルに数えないのです。

```slide ゼロベクトルを除く理由
    A 0 = 0 = λ 0

    どの λ でも成り立つ
          ▼
    固有ベクトルに数えない
```

ここまでをまとめます。
「固有ベクトル」は、Aを掛けても向きが変わらないベクトルでした。
「固有値」は、そのときの長さの倍率でした。
では、固有値はどうやって見つければよいのでしょうか。

```slide ここまでのまとめ
  固有ベクトル   向きが変わらない
  固有値         長さの倍率
```

ここからは、二つ目の「特性方程式を導く」です。
さっきは、たまたま見つけたベクトルで確かめました。
しかし、大きな行列では、当てずっぽうでは見つかりません。
そこで、固有値だけを先に求める方法を考えます。

```slide 今日の流れ
    1. 向きが変わらないベクトル
  ▶ 2. 特性方程式を導く
    3. 例で解く
    4. まとめ
```

方針は、さっきの式を変形して、xを消すことです。
まず、右辺のλ倍のxを、左辺に移します。
左辺は、xにAを掛けたものから、xのλ倍を引いた形になります。
ここまでは、「移項」しただけです。

```slide 式を変形する
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  A x = λ x

  A x − λ x = 0          (1) 移項
  ？
  ？
  ？
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

次に、xを右側にくくり出したいところです。
ただし、行列Aから、数のλを直接は引けません。
そこで、λに単位行列Iを掛けて、行列にそろえます。
単位行列は、掛けても相手を変えない行列です。
これで、xを「くくる」ことができました。

```slide 式を変形する
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  A x = λ x

  A x − λ x = 0          (1) 移項
  (A − λI) x = 0         (2) くくる
  ？
  ？
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

ここで、二つ目の式に注目してください。
括弧の中の行列は、ゼロでないxを、ゼロに送っています。
もし逆行列があれば、両辺に掛けて、xはゼロになるはずです。
xはゼロでないので、この行列は「逆行列なし」です。

```slide 式を変形する
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  A x = λ x

  A x − λ x = 0          (1) 移項
  (A − λI) x = 0         (2) くくる
  A − λI は逆行列なし    (3) 逆行列
  ？
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

逆行列を持たない行列は、「行列式」がゼロになるのでした。
だから、括弧の中の行列の行列式は、ゼロです。
この式には、もうxが出てきません。
要点は、λだけの方程式が手に入った、ということです。

```slide 式を変形する
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  A x = λ x

  A x − λ x = 0          (1) 移項
  (A − λI) x = 0         (2) くくる
  A − λI は逆行列なし    (3) 逆行列
  det(A − λI) = 0        (4) 行列式
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

この方程式を、Aの「特性方程式」と呼びます。
画面のdetは、行列式を表す記号です。
左辺を計算すると、λの多項式になります。
覚えてほしいのは、特性方程式の解が「固有値」だ、ということです。

```slide 特性方程式
  det(A − λI) = 0

      │
      ▼
  解 λ  が 固有値
```

導き方を、短く振り返ります。
ゼロでないxをゼロに送る行列は、逆行列を持ちません。
だから行列式がゼロになり、λだけの式が残りました。
これが、特性方程式です。

```slide 式を変形する
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  A x = λ x

  A x − λ x = 0          (1) 移項
  (A − λI) x = 0         (2) くくる
  A − λI は逆行列なし    (3) 逆行列
  det(A − λI) = 0        (4) 行列式
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

ここからは、三つ目の「例で解く」です。
最初に見た行列Aの固有値を、特性方程式で求めます。
答えの一つは、すでに見つけた3のはずです。
もう一つの固有値は、いくつになるでしょうか。

```slide 今日の流れ
    1. 向きが変わらないベクトル
    2. 特性方程式を導く
  ▶ 3. 例で解く
    4. まとめ
```

まず、Aからλ倍の単位行列を引きます。
単位行列は、対角に1が並ぶ行列です。
なので、引くと、Aの対角の成分だけからλが引かれます。
対角以外の1は、そのまま残ります。

```slide A の特性方程式を解く
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
            ┌ 2−λ   1  ┐
   A − λI = └  1   2−λ ┘

   ？
   ？
   ？
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

次に、この行列の行列式を計算します。
二行二列の行列式は、対角の積から、もう一方の対角の積を引いたものでした。
ここでは、二引くλの二乗から、一掛ける一を引きます。
展開すると、λの二次式になります。

```slide A の特性方程式を解く
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
            ┌ 2−λ   1  ┐
   A − λI = └  1   2−λ ┘

   det = (2−λ)² − 1 = λ² − 4λ + 3
   ？
   ？
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

続いて、この二次式をゼロと置いて解きます。
因数分解すると、λ引く1と、λ引く3の積になります。
したがって、固有値は1と3です。
予想どおり、さっき見つけた3が含まれていました。

```slide A の特性方程式を解く
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
            ┌ 2−λ   1  ┐
   A − λI = └  1   2−λ ┘

   det = (2−λ)² − 1 = λ² − 4λ + 3
   (λ − 1)(λ − 3) = 0
   λ = 1, 3
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

では、固有値1の固有ベクトルを探します。
λに1を入れると、行列はAからIを引いたものです。
この行列をxに掛けると、どちらの成分も、xの「成分の和」になります。
和がゼロなら、ゼロに送られます。
つまり、成分が1とマイナス1のベクトルが、固有ベクトルです。

```slide 固有値 1 の固有ベクトル
   A − I = ┌ 1  1 ┐
           └ 1  1 ┘

   成分の和 = 0
        ▼
   x = (1, −1)
```

本当に固有ベクトルか、Aを掛けて確かめましょう。
計算すると、同じ1と、マイナス1が返ってきます。
向きも長さも変わらないので、倍率は1です。
固有値1の固有ベクトルは、成分が1とマイナス1のベクトルでした。

```slide 確かめる
   A (1, −1) = (2 − 1, 1 − 2)
             = (1, −1)

   倍率 1  ＝  固有値 1
```

例で解いた流れを振り返ります。
AからλIを引き、その行列式をゼロと置きました。
二次方程式を解くと、固有値は1と3でした。
ポイントは、どの二行二列の行列でも、同じ手順で解けることです。

```slide 解き方の手順
  1. A − λI を作る
  2. 行列式 = 0 と置く
  3. λ の方程式を解く
  4. 戻して x を求める
```

最後に、今日の内容をまとめます。
「固有ベクトル」は、Aを掛けても向きが変わらないベクトルです。
「固有値」は、そのときの長さの倍率です。
「特性方程式」は、行列式をゼロと置いた、λだけの方程式です。

```slide まとめ
  固有ベクトル   向きが変わらない
  固有値         長さの倍率
  特性方程式     det(A − λI) = 0
```

最後に、次回の内容を予告します。
次回は、固有ベクトルを並べて、行列を「対角化」する方法を見ます。
対角化を使うと、行列を何回も掛ける計算が、ぐっと楽になります。
今日の特性方程式が、その出発点です。
ご視聴ありがとうございました。

```slide 次回
  対角化

      │
      ▼

  行列の累乗が楽になる
```
